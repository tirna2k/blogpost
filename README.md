# Deno Project

A small TypeScript starter project for Deno.

## Requirements

- Deno

## Commands

```powershell
deno task start
deno task dev
deno task test
deno task check
```

## Structure

- `main.ts` contains the starter program.
- `main_test.ts` contains unit tests.
- `deno.json` defines tasks, imports, and TypeScript settings.
